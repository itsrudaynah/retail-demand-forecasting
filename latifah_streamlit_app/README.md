# Retail Demand Forecasting - Streamlit Prototype

Interactive Streamlit prototype for retail demand forecasting.

## Current Scope
- Store 1
- Product Family: BEVERAGES
- 15-day forecast horizon
- Seasonal Naive and XGBoost comparison

## Features
- Model performance metrics
- Interactive forecast visualization
- 15-day forecast results
- CSV export

## Run
pip install -r requirements.txt
streamlit run app.py
